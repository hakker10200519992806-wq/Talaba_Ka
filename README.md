# CppUz Kamola - APK qurish
1. GitHub'da yangi repozitoriy oching (Private tavsiya).
2. Shu papka ichidagi hamma narsani yuklang (sudrab tashlang).
3. .github papkasi yuklanmasa: Add file > Create new file, nomiga .github/workflows/apk.yml yozib, github-workflow-apk.yml matnini joylang.
4. Actions bo'limida qurish tugagach (5-8 daqiqa) Artifacts > cppuz-kamola-apk ni yuklab oling (ichida app-debug.apk).
Ilovani yangilash: www/ ichidagi fayllarni almashtiring, sw.js dagi kesh raqamini oshiring.
